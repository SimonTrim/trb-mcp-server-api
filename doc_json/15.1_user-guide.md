## Introduction[​](#introduction "Direct link to Introduction")

The **Agentic Platform SDK for TypeScript** is a comprehensive, type-safe library designed to simplify interaction with Trimble's Agentic Platform services.

It provides a unified interface for building AI-powered applications with enterprise-grade reliability, security, and developer experience.

### SDK Architecture[​](#sdk-architecture "Direct link to SDK Architecture")

The SDK is built around a central `AgenticPlatformSdk` class that provides access to five core services:

```typescript
import {
  AgenticPlatformSdk,
  Environments,
  createAuthProvider,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

const sdk = new AgenticPlatformSdk({
  environment: Environments.Development,
  authProvider: createAuthProvider(async () => 'your-token'),
  timeoutInMs: 30000, // optional
  retries: 3, // optional
});

// Access individual services
sdk.agents; // AgentsService - AI agent management
sdk.knowledge; // KnowledgeService - Knowledge base operations
sdk.models; // ModelsService - AI model discovery
sdk.ingestion; // IngestionService - Document processing
sdk.evals; // EvalsService - Evaluation datasets and jobs

```

The SDK uses a flexible token provider pattern for authentication. You provide an asynchronous function that returns a valid JWT access token.

```typescript
  AgenticPlatformSdk,
  Environments,
  createAuthProvider,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

// Simple token provider
const authProvider = createAuthProvider(async () => {
  return 'your-jwt-access-token';
});

const sdk = new AgenticPlatformSdk({
  environment: Environments.Development,
  authProvider,
});

```

#### Server-Side with Automatic Token Refresh[​](#server-side-with-automatic-token-refresh "Direct link to Server-Side with Automatic Token Refresh")

For production applications, implement automatic token refresh. This example uses a client secret, so it must run on the server only. Do not include client secrets in browser code.

```typescript
class TokenManager {
  private accessToken: string | null = null;
  private refreshToken: string;
  private tokenExpiry: Date | null = null;

  constructor(refreshToken: string) {
    this.refreshToken = refreshToken;
  }

  async getAccessToken(): Promise<string> {
    // Return cached token if still valid
    if (this.accessToken && this.tokenExpiry && new Date() < this.tokenExpiry) {
      return this.accessToken;
    }
    return this.refreshAccessToken();
  }

  async onUnauthorized(): Promise<string> {
    // Called automatically on 401 errors
    return this.refreshAccessToken();
  }

  private async refreshAccessToken(): Promise<string> {
    const response = await fetch('https://your-auth-server.com/token', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'refresh_token',
        refresh_token: this.refreshToken,
        client_id: process.env.CLIENT_ID!,
        client_secret: process.env.CLIENT_SECRET!,
      }),
    });

    const data = await response.json();
    this.accessToken = data.access_token;
    this.tokenExpiry = new Date(Date.now() + data.expires_in * 1000);

    return this.accessToken;
  }
}

// Initialize SDK with auto-refresh
const tokenManager = new TokenManager(process.env.REFRESH_TOKEN!);
const authProvider = createAuthProvider(
  () => tokenManager.getAccessToken(),
  () => tokenManager.onUnauthorized()
);

const sdk = new AgenticPlatformSdk({
  environment: Environments.Production,
  authProvider,
  timeoutInMs: 30000,
  retries: 3,
  maxAuthRetries: 2,
});

```

#### Browser Application (No Auto-Retry)[​](#browser-application-no-auto-retry "Direct link to Browser Application (No Auto-Retry)")

For browser apps where 401 errors should trigger a login UI:

```typescript
const authProvider = createAuthProvider(async () => {
  const token = localStorage.getItem('access_token');
  if (!token) {
    window.location.href = '/login';
    throw new Error('No token available');
  }
  return token;
});

const sdk = new AgenticPlatformSdk({
  environment: Environments.Production,
  authProvider,
});

// Handle 401 errors in your application
try {
  await sdk.agents.list();
} catch (error) {
  if (error instanceof HttpError && error.errorPayload?.status === 401) {
    localStorage.removeItem('access_token');
    window.location.href = '/login';
  }
}

```

## Advanced Topics[​](#advanced-topics "Direct link to Advanced Topics")

### Pagination[​](#pagination "Direct link to Pagination")

The SDK provides a unified pagination interface across all services.

#### Understanding PaginatedResponse[​](#understanding-paginatedresponse "Direct link to Understanding PaginatedResponse")

```typescript
type PaginatedResponse<T> = {
  data: T; // Current page data
  next?: () => Promise<PaginatedResponse<T>>; // Function to fetch next page
  prev?: () => Promise<PaginatedResponse<T>>; // Function to fetch previous page (Models only)
};

```

#### Basic Pagination[​](#basic-pagination "Direct link to Basic Pagination")

```typescript
// Fetch first page
const firstPage = await sdk.agents.list({ pageSize: 20 });

console.log('First page:', firstPage.data.items.length);

// Fetch next page if available
if (firstPage.next) {
  const secondPage = await firstPage.next();
  console.log('Second page:', secondPage.data.items.length);
}

```

#### Iterating Through All Pages[​](#iterating-through-all-pages "Direct link to Iterating Through All Pages")

```typescript
async function fetchAllItems<T extends { items: any[] }>(
  firstPage: PaginatedResponse<T>
): Promise<any[]> {
  const allItems = [...firstPage.data.items];
  let currentPage = firstPage;

  while (currentPage.next) {
    currentPage = await currentPage.next();
    allItems.push(...currentPage.data.items);
  }

  return allItems;
}

// Usage
const firstPage = await sdk.knowledge.listLibraries({ pageSize: 50 });
const allLibraries = await fetchAllItems(firstPage);
console.log(`Total libraries: ${allLibraries.length}`);

```

#### Cursor-Based Pagination[​](#cursor-based-pagination "Direct link to Cursor-Based Pagination")

Most services use cursor-based pagination with `skipToken`:

```typescript
const agents = await sdk.agents.list({ pageSize: 20 });
// The SDK automatically handles skipToken internally
// Just call next() to get the next page

```

#### Offset-Based Pagination[​](#offset-based-pagination "Direct link to Offset-Based Pagination")

The Models Service uses offset-based pagination:

```typescript
const modelsPage = await sdk.models.list({
  pageSize: 50,
  pageIndex: 0,
});

// Navigate forward
if (modelsPage.next) {
  const nextPage = await modelsPage.next();

  // Navigate backward
  if (nextPage.prev) {
    const prevPage = await nextPage.prev();
  }
}

```

### Error Handling[​](#error-handling "Direct link to Error Handling")

#### Understanding HttpError[​](#understanding-httperror "Direct link to Understanding HttpError")

All API errors are mapped to specific error classes that extend from `HttpError`. This allows you to catch and handle specific error types easily.

```typescript
import { HttpError } from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

try {
  await sdk.agents.create({
    /* ... */
  });
} catch (error) {
  if (error instanceof HttpError) {
    console.error('HTTP Status:', error.errorPayload.status);
    console.error('Error Type:', error.errorPayload.type);
    console.error('Title:', error.errorPayload.title);
    console.error('Detail:', error.errorPayload.detail);
  } else {
    console.error('Unexpected error:', error);
  }
}

```

#### Specific Error Classes[​](#specific-error-classes "Direct link to Specific Error Classes")

The SDK provides specific error classes for all known API error types, making it easy to handle specific scenarios:

```typescript
import {
  BadRequestError,
  UnauthorizedError,
  PermissionDeniedError,
  ResourceNotFoundError,
  RateLimitError,
  InternalServerError,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

try {
  const agent = await sdk.agents.get('agent-123');
} catch (error) {
  // Catch specific error types
  if (error instanceof ResourceNotFoundError) {
    console.log('Agent not found, creating new one...');
    // Handle not found case
  } else if (error instanceof UnauthorizedError) {
    console.log('Authentication expired, redirecting to login...');
    // Redirect to login
  } else if (error instanceof PermissionDeniedError) {
    console.log('You do not have permission to access this agent');
    // Show permission error to user
  } else if (error instanceof RateLimitError) {
    console.log('Rate limit exceeded, waiting...');
    // Implement backoff strategy
    await delay(5000);
    // Retry...
  } else if (error instanceof InternalServerError) {
    console.log('Server error, please try again later');
    // Log for monitoring
  } else {
    console.error('Unexpected error:', error);
  }
}

```

**Available Error Classes by Category:**

**400 Bad Request Errors:**

* `BadRequestError` - Generic bad request
* `InvalidPayloadError` - Invalid request body
* `InvalidQueryParamError` - Invalid query parameter
* `InvalidPageSizeError` - Invalid pagination size
* `InvalidModelError` - Invalid model specification
* `ContentFilterError` - Content blocked by content filter
* `MissingContextError` - Required context missing
* And many more specific validation errors...

**401 Unauthorized:**

* `UnauthorizedError` - Authentication required or failed

**403 Forbidden:**

* `PermissionDeniedError` - Insufficient permissions

**404 Not Found:**

* `ResourceNotFoundError` - Resource does not exist
* `InvalidUrlError` - Invalid endpoint URL

**409 Conflict:**

* `ConflictError` - Generic conflict
* `StaleObjectError` - Resource modified (optimistic locking)

**422 Unprocessable Content:**

* `UnprocessableContentError` - Validation error
* `InvalidAgentIconError` - Invalid agent icon format

**429 Too Many Requests:**

* `RateLimitError` - Generic rate limit
* `RunQuotaExceededError` - Agent run quota exceeded
* `TokenQuotaExceededError` - Token quota exceeded

**5xx Server Errors:**

* `InternalServerError` - Generic server error
* `BadGatewayError` - Gateway error
* `ServiceUnavailableError` - Service temporarily unavailable

**Agent-Specific Errors:**

* `BadAgentConfigurationError` - Invalid agent configuration
* `TurnLimitExceededError` - Agent turn limit exceeded
* `UnexpectedToolCallError` - Unexpected tool call in stream

#### Common Error Types[​](#common-error-types "Direct link to Common Error Types")

| Status | Type                       | Description              | Action                                 |
| ------ | -------------------------- | ------------------------ | -------------------------------------- |
| 400    | `tag:InvalidPayload`       | Invalid request data     | Check request parameters               |
| 401    | `tag:UnAuthorized`         | Authentication failed    | Refresh token, check credentials       |
| 403    | `tag:PermissionDenied`     | Insufficient permissions | Check user permissions                 |
| 404    | `tag:ResourceNotFound`     | Resource not found       | Verify resource ID                     |
| 409    | `tag:Conflict`             | Resource conflict        | Handle conflict (e.g., duplicate ID)   |
| 422    | `tag:UnprocessableContent` | Validation error         | Fix validation errors                  |
| 429    | `tag:RateLimit`            | Rate limit exceeded      | Implement backoff, reduce request rate |
| 500    | `tag:InternalServerError`  | Server error             | Retry with backoff                     |
| 503    | `tag:ServiceUnavailable`   | Service unavailable      | Retry with backoff                     |

#### Automatic Retries[​](#automatic-retries "Direct link to Automatic Retries")

The SDK automatically retries requests in these scenarios:

* **401 Unauthorized**: Calls `authProvider.onUnauthorized()` if provided
* **429 Rate Limit**: Retries with exponential backoff
* **5xx Server Errors**: Retries transient errors with exponential backoff
* **Network Errors**: Retries on connectivity issues

```typescript
// Configure retry behavior
const sdk = new AgenticPlatformSdk({
  environment: Environments.Production,
  authProvider,
  retries: 3, // Number of retry attempts (default: 3)
  maxAuthRetries: 2, // Max auth retry attempts (default: 1)
});

```

#### Handling Specific Errors[​](#handling-specific-errors "Direct link to Handling Specific Errors")

With specific error classes, you can use `instanceof` checks instead of string comparisons:

```typescript
import {
  InvalidPayloadError,
  PermissionDeniedError,
  RateLimitError,
  InternalServerError,
  ResourceNotFoundError,
  UnauthorizedError,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

try {
  await sdk.agents.create(agentConfig);
} catch (error) {
  if (error instanceof InvalidPayloadError) {
    console.error('Invalid configuration:', error.errorPayload.detail);
    // Show validation errors to user
    showValidationErrors(error.errorPayload);
  } else if (error instanceof PermissionDeniedError) {
    console.error('Insufficient permissions');
    // Redirect to access request page
    redirectToAccessRequest();
  } else if (error instanceof RateLimitError) {
    console.error('Rate limit exceeded');
    // Implement backoff strategy
    await delay(5000);
    // Retry...
  } else if (error instanceof InternalServerError) {
    console.error('Server error, retrying...');
    // Already retried automatically, log for monitoring
    logErrorToMonitoring(error);
  } else if (error instanceof ResourceNotFoundError) {
    console.error('Resource not found');
    // Handle not found case
    showNotFoundMessage();
  } else if (error instanceof UnauthorizedError) {
    console.error('Authentication failed');
    // Redirect to login
    redirectToLogin();
  } else {
    console.error('Unexpected error:', error);
  }
}

```

**Real-World Example: Agent Creation with Error Handling**

```typescript
import {
  InvalidPayloadError,
  InvalidModelError,
  PermissionDeniedError,
  BadAgentConfigurationError,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

async function createAgentWithErrorHandling(config: CreateAgentConfigRequest) {
  try {
    const agent = await sdk.agents.create(config);
    console.log('✓ Agent created successfully:', agent.id);
    return agent;
  } catch (error) {
    if (error instanceof InvalidPayloadError) {
      console.error('✗ Invalid agent configuration');
      console.error('  Details:', error.errorPayload.detail);
      // Parse and display specific validation errors to user
      throw new Error('Please fix the configuration errors and try again');
    } else if (error instanceof InvalidModelError) {
      console.error('✗ Invalid model specified');
      console.error('  Available models:', await getAvailableModels());
      throw new Error('Please select a valid model');
    } else if (error instanceof PermissionDeniedError) {
      console.error('✗ You do not have permission to create agents');
      throw new Error('Please request agent creation permissions');
    } else if (error instanceof BadAgentConfigurationError) {
      console.error('✗ Agent configuration validation failed');
      console.error('  Details:', error.errorPayload.detail);
      throw new Error('Agent configuration is invalid');
    } else {
      console.error('✗ Unexpected error:', error);
      throw error;
    }
  }
}

```

### Best Practices[​](#best-practices "Direct link to Best Practices")

#### 1. Token Management[​](#1-token-management "Direct link to 1. Token Management")

```typescript
// ✅ Good: Implement token caching and refresh
class TokenManager {
  private token: string | null = null;
  private expiry: Date | null = null;

  async getAccessToken(): Promise<string> {
    if (this.token && this.expiry && new Date() < this.expiry) {
      return this.token;
    }
    return this.refreshToken();
  }

  private async refreshToken(): Promise<string> {
    // Fetch new token
    // Update this.token and this.expiry
    return this.token!;
  }
}

// ❌ Bad: Fetch token on every request
const authProvider = createAuthProvider(async () => {
  const response = await fetch('/api/token'); // Slow!
  return (await response.json()).token;
});

```

```typescript
// ✅ Good: Handle errors appropriately
```
