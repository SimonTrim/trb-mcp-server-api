# Ingestion

The Ingestion Service is designed to be used as part of Trimble Agentic AI Platform to ingest documents into the Knowledge Service. It exposes a simple API to process documents and ingest them into Knowledge Service libraries.

## Capabilities Overview[​](#capabilities-overview "Direct link to Capabilities Overview")

### Document Ingestion[​](#document-ingestion "Direct link to Document Ingestion")

* **Ingest a file into a library via URL** - Provide a download URL for the service to fetch and process your document
* **Ingest a file into a library via upload** - Upload files directly to the service for processing

### Job Management[​](#job-management "Direct link to Job Management")

* **Monitor ingestion job status** - Track the progress of your ingestion jobs in real-time

  <!-- -->

  * View detailed status information as jobs progress through different stages
  * Access error messages when jobs fail for debugging and troubleshooting

* **List recent ingestion jobs** - View a history of ingestion jobs

* **Get an ingestion by ID** - Retrieve detailed information about a specific ingestion job

### Processing Stages[​](#processing-stages "Direct link to Processing Stages")

Each ingestion job goes through multiple stages:

* `UPLOADABLE` - Waiting for content to be uploaded
* `QUEUED` - Content is available, waiting for parsing to start
* `PARSING` - Parsing of the content into text is in progress
* `PARSED` - Parsing completed, waiting for chunking to start
* `CHUNKING` - Chunking phase is in progress
* `COMPLETED` - Final job state indicating success
* `FAILED` - Final job state indicating an error occurred

### Supported File Formats[​](#supported-file-formats "Direct link to Supported File Formats")

The service supports a wide range of file formats with automatic parsing strategy selection:

#### Complex Documents (using Document Intelligence)[​](#complex-documents-using-document-intelligence "Direct link to Complex Documents (using Document Intelligence)")

* PDF (`.pdf`)
* Microsoft Word (`.docx`)
* Microsoft Excel (`.xlsx`)
* Microsoft PowerPoint (`.pptx`)

#### Text-Based Documents[​](#text-based-documents "Direct link to Text-Based Documents")

* Text files: `.txt`, `.log`, `.md`, `.markdown`, `.rst`
* Data files: `.csv`, `.tsv`, `.json`, `.xml`, `.yaml`, `.yml`
* Web files: `.html`, `.htm`, `.css`
* Programming languages: `.py`, `.js`, `.ts`, `.java`, `.go`, `.rb`, `.php`, and many more
* Configuration files: `.ini`, `.conf`, `.cfg`, `.properties`, `.env`
