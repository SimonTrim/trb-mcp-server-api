# Service Examples

Practical usage snippets for the SDK clients. These are SDK-focused and omit platform semantics.

## Agents service examples[​](#agents-service-examples "Direct link to Agents service examples")

#### Creating an agent[​](#creating-an-agent "Direct link to Creating an agent")

```typescript
import {
  AgenticPlatformSdk,
  Environments,
  createAuthProvider,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

const authProvider = createAuthProvider(async () => 'your-access-token');

const sdk = new AgenticPlatformSdk({
  environment: Environments.Development,
  authProvider,
});

const newAgent = await sdk.agents.create({
  name: 'Customer Support Agent',
  description: 'An AI agent specialized in customer support',
  models: [
    {
      name: 'gpt-4o',
      temperature: 0.7,
      maxOutputTokens: 2000,
    },
  ],
  shortMemorySize: 10,
  systemPrompt:
    'You are a helpful customer support assistant. Always be polite and professional.',
});

console.log('Created agent:', newAgent);

```

#### Searching agents and threads[​](#searching-agents-and-threads "Direct link to Searching agents and threads")

```typescript
// Search agents by name or description with relevance scoring
const searchResults = await sdk.agents.searchAgents('customer support', {
  pageSize: 10,
  fields: ['highlights'], // Include text snippets showing matches
  sortBy: '-score', // Sort by relevance (default)
});

console.log('Search results:', searchResults.data.items);

// Access results with scores and highlights
searchResults.data.items.forEach(item => {
  if (item.type === 'agents') {
    console.log(`${item.result.name} (relevance: ${item.score})`);
    if (item.highlights) {
      console.log('Matching text:', item.highlights);
    }
  }
});

if (searchResults.next) {
  const nextPage = await searchResults.next();
  console.log('Next page results:', searchResults.data.items.length);
}

// Search threads by title or content
const threadResults = await sdk.agents.searchThreads('installation guide', {
  pageSize: 10,
});

console.log('Found threads:', threadResults.data.items.length);

```

## Advanced usage patterns[​](#advanced-usage-patterns "Direct link to Advanced usage patterns")

### Pagination[​](#pagination "Direct link to Pagination")

The SDK provides a unified pagination interface across all list operations. All paginated responses return a `PaginatedResponse<T>` type with the following structure:

```typescript
import { PaginatedResponse } from '@trimble-agentic-external-npm-local/agentic-platform-sdk-ts';

type PaginatedResponse<T> = {
  data: T; // The current page of data
  next?: () => Promise<PaginatedResponse<T>>; // Function to fetch next page
  prev?: () => Promise<PaginatedResponse<T>>; // Function to fetch previous page
};

```

**Basic pagination:**

```typescript
// Fetch first page
const firstPage = await sdk.agents.list({ pageSize: 10 });
console.log('First page:', firstPage.data.items);

// Fetch next page if available
if (firstPage.next) {
  const secondPage = await firstPage.next();
  console.log('Second page:', secondPage.data.items);
}

```

**Fetching all pages:**

```typescript
// Helper function to collect all items across all pages
async function fetchAllPages<T>(
  firstPage: PaginatedResponse<T & { items: any[] }>
): Promise<any[]> {
  const allItems = [...firstPage.data.items];
  let currentPage = firstPage;

  while (currentPage.next) {
    currentPage = await currentPage.next();
    allItems.push(...currentPage.data.items);
  }

  return allItems;
}

// Usage
const firstPage = await sdk.agents.list({ pageSize: 50 });
const allAgents = await fetchAllPages(firstPage);
console.log(`Retrieved ${allAgents.length} agents across all pages`);

```

**Cursor-based pagination:**

Most services use cursor-based pagination with `skipToken` for efficient navigation through large datasets:

```typescript
// The SDK automatically handles skipToken internally
const agents = await sdk.agents.list({ pageSize: 20 });
// next() automatically includes the correct skipToken
if (agents.next) {
  const nextPage = await agents.next(); // skipToken handled automatically
}

```

**Bidirectional pagination (Models service):**

The Models Service supports both forward and backward navigation when `next`/`prev` links are available:

```typescript
// Models service supports both next and prev
const modelsPage = await sdk.models.list({ pageSize: 50, pageIndex: 0 });

// Navigate forward
if (modelsPage.next) {
  const nextPage = await modelsPage.next();

  // Navigate backward
  if (nextPage.prev) {
    const previousPage = await nextPage.prev();
  }
}

```

**Pagination best practices:**

* Use appropriate `pageSize` based on your use case (default is typically 20-100)
* Implement pagination UI to avoid loading too many items at once
* Consider caching paginated results when appropriate
* Handle pagination loading states in your UI
* Always check if `next` exists before calling it

### Batch operations[​](#batch-operations "Direct link to Batch operations")

```typescript
// Create multiple agents in parallel
const agentConfigs = [
  { name: 'Agent 1', systemPrompt: 'You are agent 1' },
  { name: 'Agent 2', systemPrompt: 'You are agent 2' },
  { name: 'Agent 3', systemPrompt: 'You are agent 3' },
];

const agents = await Promise.all(
  agentConfigs.map(config => sdk.agents.create(config))
);

```
