# Overview

The Agentic Platform provides three ways to build AI agent applications, each offering different levels of control and customization. Choose the approach that best fits your needs based on your requirements for customization, control, and development complexity.

## Three Approaches to Building AI Agent Apps[​](#three-approaches-to-building-ai-agent-apps "Direct link to Three Approaches to Building AI Agent Apps")

### 1. Iframe Embedding (Easiest)[​](#1-iframe-embedding-easiest "Direct link to 1. Iframe Embedding (Easiest)")

**Best for:** Quick integration, minimal setup, standard UI requirements

Embed the Trimble Assist application directly into your web application using an iframe. This is the fastest way to get started and requires minimal code.

**Key Features:**

* Pre-built, fully functional UI
* Minimal configuration required
* Automatic updates and maintenance
* Built-in authentication and session management

### 2. TypeScript SDK (Medium Complexity)[​](#2-typescript-sdk-medium-complexity "Direct link to 2. TypeScript SDK (Medium Complexity)")

**Best for:** Custom UI with SDK support, more control over the user experience

Use the TypeScript SDK to integrate Trimble Assist functionality into your own custom UI while leveraging the platform's built-in capabilities.

**Key Features:**

* Full control over UI/UX design
* Access to SDK helpers and utilities
* Bi-directional communication with the platform
* Custom tool callbacks and event handling

### 3. REST APIs (Most Flexible)[​](#3-rest-apis-most-flexible "Direct link to 3. REST APIs (Most Flexible)")

**Best for:** Complete control, custom UI from ground up, maximum flexibility

Build your application from scratch using the Agentic Platform REST APIs. This approach gives you complete control over every aspect of your application.

**Key Features:**

* Complete UI/UX freedom
* Full control over all interactions
* Custom authentication flows
* Platform-agnostic implementation

## Choosing the Right Approach[​](#choosing-the-right-approach "Direct link to Choosing the Right Approach")

| Approach             | Setup Time   | Customization | Control | Best For                             |
| -------------------- | ------------ | ------------- | ------- | ------------------------------------ |
| **Iframe Embedding** | ⚡ Fastest   | Limited       | Low     | Quick prototypes, standard use cases |
| **TypeScript SDK**   | 🕐 Medium    | High          | Medium  | Custom UI with platform features     |
| **REST APIs**        | 🐌 Most Time | Complete      | Full    | Fully custom applications            |
