## Image Generation[​](#image-generation "Direct link to Image Generation")

### Basic Concepts[​](#basic-concepts "Direct link to Basic Concepts")

Image generation turns text descriptions into images. You provide a prompt (what you want to see), and the service returns one or more images.

### Request Parameters[​](#request-parameters "Direct link to Request Parameters")

#### Required Parameters[​](#required-parameters "Direct link to Required Parameters")

* **`model`** - Which image generator to use
* **`prompt`** - Describe what you want to see

#### Optional Parameters[​](#optional-parameters "Direct link to Optional Parameters")

* **`n`** - How many images to generate (1-4, default: 1)

* **`size`** - Image dimensions:

  <!-- -->

  * `1024x1024` - Square (social media, avatars)
  * `1792x1024` - Wide landscape (banners, headers)
  * `1024x1792` - Tall portrait (mobile screens)

* **`quality`** - Image quality:

  <!-- -->

  * `standard` - Good quality, faster generation
  * `hd` - Higher quality, takes longer

## Image Editing[​](#image-editing "Direct link to Image Editing")

### How It Works[​](#how-it-works "Direct link to How It Works")

1. Upload your image to get a file ID
2. Send an edit request with the file ID and your instructions
3. Receive the edited image

### Step 1: Upload Your Image[​](#step-1-upload-your-image "Direct link to Step 1: Upload Your Image")

```bash
POST https://models.ai.trimble.com/v1/files
Authorization: Bearer <your-token>

```

```json
{
"filename": "original.jpg",
"purpose": "image-edit",
"content_type": "image/jpeg"
}

```

**Response:**

```json
{
"id": "file_abc123",
"uploadUrl": "https://model-files.ai.trimble.com/model-files/uploads/...",
"url": "https://models.ai.trimble.com/v1/files/file_abc123/content?exp=...&sig=..."
}

```

Upload your image to the `uploadUrl`:

```bash
PUT <uploadUrl>
Content-Type: image/jpeg

<your-image-data>

```

### Step 2: Edit the Image[​](#step-2-edit-the-image "Direct link to Step 2: Edit the Image")

Use the `url` from the upload response in your edit request:

```bash
POST https://models.ai.trimble.com/openai/v1/images/edits
Authorization: Bearer <your-token>

```

```json
{
"model": "gpt-image-1",
"image": "https://models.ai.trimble.com/v1/files/file_abc123/content?exp=...&sig=...",
"prompt": "Change the background to a beach scene"
```

**Response:**

```json
  {
    "url": "https://models.ai.trimble.com/v1/files/xyz789/content?exp=...&sig=..."
```

#### Required Parameters[​](#required-parameters-1 "Direct link to Required Parameters")

#### Optional Parameters[​](#optional-parameters-1 "Direct link to Optional Parameters")

* **`model`** - Which editor to use

### Tracking Provider Requests[​](#tracking-provider-requests "Direct link to Tracking Provider Requests")

#### Why Track Requests?[​](#why-track-requests "Direct link to Why Track Requests?")

When you generate or edit images, the service translates your request into the format required by the underlying provider (Google, Azure, etc.). Seeing the provider request helps you:

* Understand how your parameters are interpreted
* Debug issues with specific models
* Optimize your requests for better results
* Learn provider-specific features

### Endpoints[​](#endpoints "Direct link to Endpoints")

| Endpoint                        | Method | Purpose                       |
| ------------------------------- | ------ | ----------------------------- |
| `/openai/v1/images/generations` | POST   | Generate images from text     |
| `/openai/v1/images/edits`       | POST   | Edit existing images          |
| `/v1/files`                     | POST   | Create upload slot for images |
| `/v1/files`                     | GET    | List your files               |
| `/v1/files/{id}`                | GET    | Get file details              |
| `/v1/files/{id}/content`        | GET    | Access file content           |

### Common Parameters[​](#common-parameters "Direct link to Common Parameters")

| Parameter    | Type    | Used In             | Description                      |
| ------------ | ------- | ------------------- | -------------------------------- |
| `model`      | string  | Generation, Editing | Which model to use               |
| `prompt`     | string  | Generation, Editing | Text description or instructions |
| `n`          | integer | Generation, Editing | Number of images (1-4)           |
| `size`       | string  | Generation, Editing | Image dimensions                 |
| `quality`    | string  | Generation          | `standard` or `hd`               |
| `image`      | string  | Editing             | URL of image to edit             |
| `strength`   | float   | Editing             | How much to change (0.0-1.0)     |
| `extra_body` | object  | Generation, Editing | Provider-specific options        |

### File Listing Parameters[​](#file-listing-parameters "Direct link to File Listing Parameters")

| Parameter                | Type    | Description                   |
| ------------------------ | ------- | ----------------------------- |

| `sortBy`                 | string  | Sort field with +/- prefix    |

## Authentication[​](#authentication "Direct link to Authentication")

The Authentication section is where the notebook handles the process of securely obtaining an access token. This token is essential for authorizing API requests to the Model Proxy and MCP services, ensuring that only authenticated applications can interact with them.

```python
import os


def get_credential(key_name: str) -> str:
    """Retrieves a credential, prioritizing Colab secrets if available, else environment variables."""
    try:
        # Check if running in Google Colab
        from google.colab import userdata

        # Attempt to get from Colab secrets
        credential = userdata.get(key_name)
        if credential:
            print(f"✅ Retrieved '{key_name}' from Colab secrets.")
            return credential
    except (
        ImportError,
        Exception,
    ):  # ImportError for not in Colab, Exception for userdata.get() issues
        pass

    # Fallback to environment variables
    credential = os.environ.get(key_name)
    if credential:
        print(f"✅ Retrieved '{key_name}' from environment variables.")
        return credential

    return None


print("✅ Credential retrieval helper function defined.")

```

✅ Credential retrieval helper function defined.

```python
# Generate authentication token dynamically
import requests


def get_access_token() -> str:
    """Generate access token using OAuth client credentials flow.

    Returns:
        str: Access token for API authentication
    """
    token_url = "https://stage.id.trimblecloud.com/oauth/token"

    # Retrieve secrets using the helper function
    client_id = get_credential("TID_CLIENT_ID")
    client_secret = get_credential("TID_CLIENT_SECRET")

    if not client_id or not client_secret:
        raise ValueError(
            "TID_CLIENT_ID and TID_CLIENT_SECRET credentials must be set in Colab secrets or environment variables."
        )

    client_credentials = f"{client_id}:{client_secret}"
    tid_base64_value = base64.b64encode(client_credentials.encode("utf-8")).decode(
        "utf-8"
    )

    headers = {
        "grant_type": "client_credentials",
        "Content-Type": "application/x-www-form-urlencoded",
        "Authorization": f"Basic {tid_base64_value}",
    }

    data = {"scope": "models", "grant_type": "client_credentials"}

    try:
        response = requests.post(token_url, headers=headers, data=data, timeout=30)
        response.raise_for_status()
        token_data = response.json()
        access_token = token_data.get("access_token")

        if not access_token:
            raise ValueError("No access_token in response")

        print("✅ Access token generated successfully")
        print(f"⏰ Token expires in: {token_data.get('expires_in', 'unknown')} seconds")

        return access_token
    except Exception as e:
        print(f"❌ Error generating token: {e}")
        raise


# Generate token

# Create headers with authentication
AUTH_HEADERS = {
    "Authorization": f"Bearer {ACCESS_TOKEN}",
    "Content-Type": "application/json",
}
```

```python
def parse_sse_response(text: str) -> dict[str, Any]:
    """Parse Server-Sent Events (SSE) response from MCP endpoint."""
    lines = text.strip().split("\n")
    for line in lines:
        if line.startswith("data: "):
            data_content = line[6:]  # Remove 'data: ' prefix
            try:
                return json.loads(data_content)
            except json.JSONDecodeError:
                continue
    return {}
```

## Step 1: Load Local Building Image[​](#step-1-load-local-building-image "Direct link to Step 1: Load Local Building Image")

We'll use the building image from the parent directory.

```python
# Load image from a public URL
from pathlib import Path

from IPython.display import display

IMAGE_URLS = [
    "https://download-warehouse.sketchup.com/warehouse/v1.0/content/public/b8e18fcf-4d90-4459-815b-59442d1f6efb",
    "https://as1.ftcdn.net/v2/jpg/08/64/45/62/1000_F_864456239_djb2Nq2XpXlWwkkVYBlT17eY64a4VJFm.jpg",
]

DOWNLOADED_IMAGE_PATHS = []

for i, url in enumerate(IMAGE_URLS):
    IMAGE_FILENAME = f"downloaded_image_{i}.jpg"  # Assign a unique filename for each downloaded image
    IMAGE_PATH = Path(IMAGE_FILENAME)

    print(f"\n⬇️ Downloading image {i + 1} from: {url}")
    try:
        response = requests.get(url, stream=True, timeout=30)
        response.raise_for_status()
        with open(IMAGE_PATH, "wb") as f:
            for chunk in response.iter_content(chunk_size=8192):
                f.write(chunk)
        print(f"✅ Image downloaded and saved as: {IMAGE_PATH}")
        DOWNLOADED_IMAGE_PATHS.append(IMAGE_PATH)
    except requests.exceptions.RequestException as e:
        print(f"❌ Error downloading image: {e}")
        print("Please check the URL or your network connection.")
        # Continue to the next URL even if one fails
        continue

# Verify the images exist and display them
for path in DOWNLOADED_IMAGE_PATHS:
    if not path.exists():
        print(f"❌ Error: Image not found at {path}")
    else:
        # Get file info
        file_size = path.stat().st_size
        print(f"\n✅ Found image: {path.name}")
        print(f"📊 Size: {file_size:,} bytes")
```

```python
async def edit_image_with_mcp(
    image_url: str,
    prompt: str,
    model: str = "gemini-2.5-flash-image",
    n: int = 1,
    size: str = None,
    extra_body: dict[str, Any] = None,
) -> dict[str, Any]:
    """Edit an image using the MCP EditImage tool.

    Args:
        image_url: URL of the uploaded image (content URL from files API)
        prompt: Text description of the desired edit
        model: Model to use for editing (default: gemini-2.5-flash-image)
        n: Number of images to generate
        size: Output size (e.g., '1024x1024')
        extra_body: Model-specific parameters

    Returns:
        Dict containing edited image data
    """
    print("\n🎨 Editing image with MCP...")
    print(f"   Model: {model}")
    print(f"   Prompt: {prompt}")

    # Build MCP JSON-RPC request
    arguments = {"model": model, "image": image_url, "prompt": prompt, "n": n}

    if size:
        arguments["size"] = size

    if extra_body:
        arguments["extra_body"] = extra_body

    jsonrpc_request = {
        "jsonrpc": "2.0",
        "id": int(time.time()),
        "method": "tools/call",
        "params": {"name": "EditImage", "arguments": arguments},
    }

    # Set headers for MCP request
    mcp_headers = {
        "Authorization": f"Bearer {ACCESS_TOKEN}",
        "Content-Type": "application/json",
        "Accept": "application/json, text/event-stream",
    }

    async with httpx.AsyncClient(timeout=120.0) as client:
        response = await client.post(
            MCP_ENDPOINT, json=jsonrpc_request, headers=mcp_headers
        )

        if response.status_code != 200:
            print(f"❌ MCP request failed: {response.status_code}")
            print(f"Response: {response.text}")
            response.raise_for_status()

        # Parse SSE response
        result = parse_sse_response(response.text)

        if result.get("result", {}).get("isError"):
            error_content = result["result"]["content"]
            print(f"❌ MCP tool error: {error_content}")
            raise Exception(f"EditImage tool failed: {error_content}")

        # Extract the actual result content
        content = result.get("result", {}).get("content", [])
        if content:
            result_data = json.loads(content[0]["text"])
            print("✅ Image edited successfully!")
            print(f"   Generated {len(result_data['data'])} image(s)")
            return result_data
        else:
            print("❌ Unexpected response format")
            return result


print("✅ MCP function defined")
```

```python
async def attempt_merge_images_with_direct_api(
    image_urls: list[str],
    prompt: str,
    model: str = "gemini-2.5-flash-image",
    n: int = 1,
    size: str = None,
    extra_body: dict[str, Any] = None,
) -> dict[str, Any]:
    """Attempt to 'merge' images using a direct image edit API call.

    NOTE: The current Model Proxy /openai/v1/images/edits endpoint only supports
    editing a *single* input image. This function will use only the first image
    from the provided 'image_urls' list and will not actually perform a merge
    of multiple images as there is no direct API for merging multiple images
    in the current Model Proxy setup.

    Args:
        image_urls: List of URLs of the images to conceptually merge. Only the first will be used.
        prompt: Text description of the desired edit (applied to the first image).
        model: Model to use for editing (default: gemini-2.5-flash-image)
        n: Number of output images to generate from the single input image.
        size: Output size (e.g., '1024x1024')
        extra_body: Model-specific parameters

    Returns:
        Dict containing edited image data
    """
    print("\n🎨 Attempting image edit via direct API call with multiple images")
    print(f"   Model: {model}")
    print(f"   Prompt: {prompt}")

    if not image_urls:
        raise ValueError("No image URLs provided.")

    request_body = {"model": model, "image": image_urls, "prompt": prompt, "n": n}

    if size:
        request_body["size"] = size

    if extra_body:
        request_body["extra_body"] = extra_body

    # Assuming a direct image edit endpoint at /openai/v1/images/edits
    DIRECT_EDIT_ENDPOINT = f"{MODEL_PROXY_BASE_URL}/openai/v1/images/edits"

    async with httpx.AsyncClient(timeout=120.0) as client:
        response = await client.post(
            DIRECT_EDIT_ENDPOINT, json=request_body, headers=AUTH_HEADERS
        )

        if response.status_code != 200:
            print(f"❌ Direct API request failed: {response.status_code}")
            print(f"Response: {response.text}")
            response.raise_for_status()

        result_data = response.json()
        print("✅ Image edited successfully via direct API!")
        print(f"   Generated {len(result_data['data'])} image(s)")
        return result_data
```
