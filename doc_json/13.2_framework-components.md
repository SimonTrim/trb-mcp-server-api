# Framework Components

The Agentic AI Platform provides official wrapper components for popular frontend frameworks, simplifying the integration of the iframe into your applications. These components handle all the iframe communication, configuration, and lifecycle management automatically.

## Supported Frameworks[​](#supported-frameworks "Direct link to Supported Frameworks")

| Framework   | Package                                                                | Status         |
| ----------- | ---------------------------------------------------------------------- | -------------- |
| **React**   | `@trimble-agentic-external-npm-local/agentic-chat-react@0.0.2-rc.11`   | ✅ Available   |
| **Angular** | `@trimble-agentic-external-npm-local/agentic-chat-angular@0.0.2-rc.10` | ✅ Available   |
| **Vue**     | `@trimble-agentic-external-npm-local/agentic-chat-vue`                 | 🚧 Coming Soon |

## When to Use Framework Components[​](#when-to-use-framework-components "Direct link to When to Use Framework Components")

Framework components are ideal when:

* ✅ You're building with a supported framework (React, Angular, Vue)
* ✅ You want a simpler, more declarative API
* ✅ You prefer framework-native patterns (hooks, props, components)
* ✅ You want automatic lifecycle management and cleanup

Consider using the [base iframe SDK](/docs/build/iframe-embedding/host-integration.md) directly if:

* ❌ You need maximum control over iframe communication
* ❌ You're using an unsupported framework
* ❌ You have complex custom messaging requirements
* ❌ You want to have custom localization or configuration logic that doesn't fit the component props
* ❌ You want to access the development environment features not yet exposed in stage or prod. This is not recommended, with the staging environment being the preferred initial environment.

## React[​](#react "Direct link to React")

The React wrapper provides components that integrate seamlessly with React applications, using hooks for state management and automatic cleanup on unmount.

### Installation[​](#installation "Direct link to Installation")

```bash
npm install @trimble-agentic-external-npm-local/agentic-chat-react

```

### Available Components[​](#available-components "Direct link to Available Components")

The package exports two main components:

| Component            | Description                                                                                                                                                                                        |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AgenticFullChat`    | Full-featured Assist interface with agent selection and conversation history.                                                                                                                      |
| `AgenticMinimalChat` | Streamlined chat interface focused on the core conversation experience. No agent selection other than the default, and no conversation history other than the exposed threads in the agent's hero. |

### Basic Usage[​](#basic-usage "Direct link to Basic Usage")

```typescript
import { AgenticFullChat } from '@trimble-agentic-external-npm-local/agentic-chat-react';
import type { ChatUiEvent } from '@trimble-agentic-external-npm-local/agentic-chat-react';

function App() {
  // Your token provider function
  const provideToken = async (): Promise<string> => {
    // Return your Trimble Identity access token
    return await getAccessToken();
  };

  // Optional: Handle chat events
  const handleEvent = (event: ChatUiEvent) => {
    console.log('Chat event:', event);
  };

  return (
    <AgenticFullChat
      provideToken={provideToken}
      onEvent={handleEvent}
      environment="prod"
      theme="light"
      agentId="your-agent-uuid"
      chatInputConfiguration={{
        buttons: [],
        hideModelSelection: false,
      }}
    />
  );
}

```

### Complete Example[​](#complete-example "Direct link to Complete Example")

```typescript
import { useState } from 'react';
import {
  AgenticFullChat,
  AgenticMinimalChat,
} from '@trimble-agentic-external-npm-local/agentic-chat-react';
import type { ChatUiEvent } from '@trimble-agentic-external-npm-local/agentic-chat-react';

type ChatVariant = 'minimal' | 'full';

function ChatPage() {
  const [variant, setVariant] = useState<ChatVariant>('full');
  const [theme, setTheme] = useState<'light' | 'dark'>('light');
  const [environment, setEnvironment] = useState<'stage' | 'prod'>('stage');

  const provideToken = async (): Promise<string> => {
    // Implement your token retrieval logic
    const response = await fetch('/api/auth/token');
    const { accessToken } = await response.json();
    return accessToken;
  };

  const handleEvent = (event: ChatUiEvent) => {
    console.log('Chat event:', event);
    // Handle events like message sent, agent response, errors, etc.
  };

  const chatInputConfiguration = {
    buttons: [],
    hideModelSelection: false,
  };

  const agentId = 'your-agent-uuid';

  return (
    <div style={{ height: '100vh', display: 'flex', flexDirection: 'column' }}>
      {/* Controls */}
      <div style={{ padding: '16px', borderBottom: '1px solid #ccc' }}>
        <select value={variant} onChange={e => setVariant(e.target.value as ChatVariant)}>
          <option value="full">Full</option>
          <option value="minimal">Minimal</option>
        </select>
        <select value={theme} onChange={e => setTheme(e.target.value as 'light' | 'dark')}>
          <option value="light">Light</option>
          <option value="dark">Dark</option>
        </select>
        <select value={environment} onChange={e => setEnvironment(e.target.value as 'stage' | 'prod')}>
          <option value="stage">Stage</option>
          <option value="prod">Prod</option>
        </select>
      </div>

      {/* Chat Component */}
      <div style={{ flex: 1, overflow: 'hidden' }}>
        {variant === 'minimal' ? (
          <AgenticMinimalChat
            provideToken={provideToken}
            onEvent={handleEvent}
            environment={environment}
            theme={theme}
            chatInputConfiguration={chatInputConfiguration}
            agentId={agentId}
          />
        ) : (
          <AgenticFullChat
            provideToken={provideToken}
            onEvent={handleEvent}
            environment={environment}
            theme={theme}
            chatInputConfiguration={chatInputConfiguration}
            agentId={agentId}
          />
        )}
      </div>
    </div>
  );
}

export default ChatPage;

```

### Using with Local Tools and Run Context (onBeforeRun)[​](#using-with-local-tools-and-run-context-onbeforerun "Direct link to Using with Local Tools and Run Context (onBeforeRun)")

The React components support the `onBeforeRun` configuration for registering local tools that can be invoked by the AI agent, as well as providing run context:

```typescript
import { AgenticFullChat } from '@trimble-agentic-external-npm-local/agentic-chat-react';
import type { OnBeforeRunConfig } from '@trimble-agentic-external-npm-local/agentic-chat-react';

function AppWithLocalTools() {
  const provideToken = async () => {
    return await getAccessToken();
  };

  const onBeforeRun: OnBeforeRunConfig = {
    tools: {
      runTime: {
        get_current_weather: {
          definition: {
            name: 'get_current_weather',
            description: 'Get the current weather for a location',
            parameters: {
              type: 'object',
              properties: {
                location: { type: 'string', description: 'City name' },
              },
              required: ['location'],
            },
          },
          callback: async (args) => {
            const { location } = args as { location: string };
            // Fetch weather data from your API
            const weather = await fetchWeather(location);
            return JSON.stringify({ temperature: weather.temp, conditions: weather.conditions });
          },
          timeOutInMs: 10000,
        },
      },
      global: {},
    },
    runContext: {
      context: [
        { description: 'Current user', value: 'john.doe@example.com' },
        { description: 'Project ID', value: 'proj-12345' },
      ],
    },
  };

  return (
    <AgenticFullChat
      provideToken={provideToken}
      environment="prod"
      theme="light"
      agentId="your-agent-uuid"
      chatInputConfiguration={{ buttons: [], hideModelSelection: false }}
      onBeforeRun={onBeforeRun}
      onBeforeRunTimeout={60000} // 60 second timeout
    />
  );
}

```

## Migration from Base iframe SDK[​](#migration-from-base-iframe-sdk "Direct link to Migration from Base iframe SDK")

If you're currently using the base iframe SDK directly and want to migrate to the framework specific components, the process is straightforward. The framework components are designed to abstract away the iframe communication and lifecycle management, so you can replace your existing implementation with the new components while keeping your configuration and token logic mostly intact:

### Before (Base iframe SDK)[​](#before-base-iframe-sdk "Direct link to Before (Base iframe SDK)")

```typescript
import { useEffect, useRef } from 'react';
import {
  listenToChatUi,
  CHAT_UI_URLS,
  type ChatUiConfiguration,
  ContentVariants,
  ChatUiVariants,
} from '@trimble-agentic-external-npm-local/agentic-platform-sdk-iframe-typescript';

function Chat() {
  const iframeRef = useRef<HTMLIFrameElement>(null);
  const environment = 'prod';
  const iframeUrl = CHAT_UI_URLS[environment];

  useEffect(() => {
    if (!iframeRef.current) return;

    const getConfig = (): ChatUiConfiguration => ({
      environment,
      agentId: 'your-agent-uuid',
      uiConfig: {
        theme: 'light',
        contentVariant: ContentVariants.Chat,
        variant: ChatUiVariants.Full,
        chatInput: { buttons: [], hideModelSelection: false },
      },
      localization: {},
    });

    const getToken = async () => token;

    const unsubscribe = listenToChatUi(
      iframeRef.current,
      iframeUrl,
      getConfig,
      getToken
    );

    return () => unsubscribe();
  }, []);

  return <iframe ref={iframeRef} src={iframeUrl} style={{ width: '100%', height: '100%' }} />;
}

```
