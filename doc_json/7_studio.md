# Studio App

The **Studio App** is a comprehensive web-based IDE for building, evaluating, and operating AI agents on the Trimble Agentic AI Platform. It provides a visual interface for the complete agent development lifecycle.

## Key Capabilities[​](#key-capabilities "Direct link to Key Capabilities")

### BUILD[​](#build "Direct link to BUILD")

Create and manage your AI agents with a user-friendly interface:

* **Agents**: Configure agent settings, system prompts, tools, and models
* **Models**: Select and configure LLM models for your agents
* **Knowledge**: Manage knowledge bases and upload documents
* **Tools**: Configure MCP servers, local tools, and built-in tools

### EVALUATE[​](#evaluate "Direct link to EVALUATE")

Test and measure agent performance before deployment:

* **Datasets**: Create and manage test datasets for agent evaluation
* **Metrics**: Define custom evaluation metrics to assess agent quality
* **Evaluation Jobs**: Run automated tests against your agents
* **Evaluations**: Review results and compare agent performance

### OPERATE[​](#operate "Direct link to OPERATE")

Monitor and observe agent behavior in production:

* **Overview**: Dashboard with key metrics and agent health
* **Usage**: Track token consumption and API usage
* **Speed**: Monitor response times and latency
* **Traces**: View detailed execution traces for debugging
* **Feedback**: Collect and review user feedback
* **Safety Violations**: Monitor content safety and policy compliance
* **Quota Violations**: Track usage limits and quota management

## Getting Started[​](#getting-started "Direct link to Getting Started")

Access the Studio App at:

* **Production**: <https://studio.ai.trimble.com>
* **Staging**: <https://studio.stage.trimble-ai.com>

The Studio App requires authentication via Trimble Identity. Once logged in, you can start building agents immediately or explore existing agents shared with you.
