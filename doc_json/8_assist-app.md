# Assist App

The **Assist App** is an end-user-facing chat interface that provides conversational access to AI agents built on the Trimble Agentic AI Platform. It offers a seamless experience for interacting with agents through natural language.

## Deployment Options[​](#deployment-options "Direct link to Deployment Options")

### Standalone Application[​](#standalone-application "Direct link to Standalone Application")

Access Assist as a full web application:

* **Production**: <https://assist.ai.trimble.com>
* **Staging**: <https://assist.stage.trimble-ai.com>

### Embeddable Version[​](#embeddable-version "Direct link to Embeddable Version")

Integrate Assist directly into your applications using iframe embedding:

* Embed the chat interface within your web application
* Maintain consistent branding and user experience
* Seamless authentication and agent access
* See [Iframe Embedding Guide](/docs/build/iframe-embedding/overview) for implementation details

## Key Features[​](#key-features "Direct link to Key Features")

### Agent Discovery[​](#agent-discovery "Direct link to Agent Discovery")

* Browse and access available agents
* View agent descriptions and capabilities
* Quick access to recently used agents
* Sample prompts to get started quickly

### Conversational Interface[​](#conversational-interface "Direct link to Conversational Interface")

* Natural language chat with AI agents
* Rich message formatting and responses
* Context-aware conversations with history
* Model selection for flexible inference options

### Conversation Management[​](#conversation-management "Direct link to Conversation Management")

* Automatic conversation history
* Search through past conversations
* Resume previous conversations
* Organize and manage chat threads

### Multi-Agent Support[​](#multi-agent-support "Direct link to Multi-Agent Support")

* Switch between different agents seamlessly
* Access specialized agents for different tasks
* Share conversations across agents (when configured)

## User Experience[​](#user-experience "Direct link to User Experience")

The Assist App is designed for end users who need to:

* Get instant answers and assistance from AI agents
* Access domain-specific knowledge and tools
* Complete tasks through conversational AI
* Leverage multiple specialized agents in their workflow

Authentication is handled via Trimble Identity, ensuring secure access to agents based on configured permissions.
